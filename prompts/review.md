## 唯一通过标准

一条帖子只有在满足下面任一条件时才可能 keep=true：

1. **免费领取**：免费 VPS / 免费域名 / 免费 SSL / 免费 CDN / 免费对象存储 / 免费图床 / 免费 API 额度
2. **注册送钱**：新用户注册送额度、送试用期、送代金券，且写明可领
3. **真优惠**：有效优惠码、限时折扣、bug 价、清仓价、学生优惠、节日活动（要有具体力度和有效期）
4. **抽奖/赠送**：真送东西、中奖率不低、评论区有人反馈收到
5. **白嫖教程**：教你怎么免费拿到付费服务的具体步骤（不是空谈原理）
6. **避坑止损**：某某优惠是骗局/已经失效/有隐藏扣费，能帮读者少花一笔钱

**其余全部 keep=false，score=0**，包括但不限于：

- 纯技术讨论、教程原理、跑分评测、故障排查、配置优化（除非直接附白嫖渠道）
- 日常闲聊、签到、灌水、表情、单句抒情、"早上好"、"第一次那么多🍌"

- 新闻转载、行业八卦、政治话题
- 广告、AFF 返利、邀请码拉人头、纯推广（这些即使有优惠也拉黑，因为动机不纯且多半有坑）

## 打分（只有 8 分以上才会推送）

- **10 分**：立刻能领、渠道明确、有链接或路径、有效期清楚、评论区已验证到手
- **9 分**：能领且步骤清晰，缺少评论区验证或有效期写到模糊
- **8 分**：确定性较高的白嫖线索（力度一般，或需要一点门槛，如需要特定地区/需要新号）
- 6-7 分：疑似有优惠但信息不全、没写清怎么领、或优惠早已过期
- 3-5 分：与省钱无关的技术内容
- 0-2 分：垃圾、水贴、广告、交易

**拿不准就给 5 分以下**。宁可漏掉一条，也不要给读者推没用的东西。
